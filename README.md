# Homebrew tap for cavelon

`cavelon` is the command-line tool and local MCP server of the
[Cavelon dev-kit](https://github.com/goodguys-gmbh/cavelon-dev-kit): it lets
you and your coding agent build, test and activate Cavelon solutions.

```bash
brew install goodguys-gmbh/cavelon/cavelon
cavelon setup
```

Update with `brew upgrade cavelon`. Works on macOS (Apple silicon and Intel)
and Linux (x64 and arm64).

The formula is written by the dev-kit's release workflow on every release;
don't edit it here. Questions and issues go to the
[dev-kit repository](https://github.com/goodguys-gmbh/cavelon-dev-kit/issues).
